# BrainDump — วางแผนการเรียน

เว็บภาษาไทยสำหรับเพิ่มงาน จัดตารางอ่านหนังสือ เตรียมสอบ และติดตามเวลาเรียน เปิดได้บน Safari, Chrome และ Edge โดยไม่ต้องสมัครบัญชี

## ใช้งาน
กด **เพิ่มงาน** → ตั้งเวลาว่างใน **ตั้งค่า** → ไป **แผนการเรียน → สร้างแผน** → ตรวจเวลาแล้วกด **ใช้แผนนี้**

บน iPhone/iPad เปิดเว็บด้วย Safari แล้วกด **แชร์ → เพิ่มไปยังหน้าจอโฮม**

งานและไฟล์แนบอยู่ในเบราว์เซอร์แต่ละเครื่อง ไม่ซิงก์ข้ามเครื่อง ใช้ **ตั้งค่า → ส่งออกข้อมูลสำรองพร้อมไฟล์แนบ** ก่อนล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง นำเข้าไฟล์สำรองได้โดยเพิ่มรวมกับงานเดิม

AI ยังไม่เปิดใช้งาน และรอบนี้ยังไม่มี APK

## ซอร์สโค้ด
ไฟล์ `braindump-source.zip` เป็นซอร์สโค้ดเต็มพร้อมคำอธิบาย ทดสอบ และไฟล์สำหรับสร้างเว็บด้วย React/TypeScript/Vite ดาวน์โหลดแล้วแตกไฟล์ จากนั้นใช้ Node.js 22.13 ขึ้นไป:

```sh
npm ci
npm run dev
npm test
npm run build
```

ไฟล์ HTML, CSS และ JavaScript ที่รากคลังนี้เป็นเวอร์ชันพร้อมเปิดใช้บน GitHub Pages ส่วนซอร์สโค้ดที่แก้ไขได้อยู่ใน ZIP

## ตั้งค่า GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root) → Save

ข้อมูลส่วนตัวของผู้ใช้ไม่ได้ถูกอัปโหลดไป GitHub
