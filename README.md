# BrainDump — วางแผนการเรียน

[เปิดเว็บ](https://padppp66.github.io/braindump/)

เพิ่มงาน จัดตารางอ่านหนังสือ เตรียมสอบ และแจ้งเตือนกำหนดส่ง

## บัญชีและข้อมูล

เข้า ตั้งค่า → เข้าสู่ระบบด้วย Google เพื่อซิงก์งานและไฟล์แนบผ่าน Supabase ข้อมูลแต่ละบัญชีแยกจากกัน งานเดิมในโหมดผู้เยี่ยมชมยังอยู่ในเครื่อง และนำเข้าบัญชีได้เมื่อคุณเลือก

ส่งออกข้อมูลสำรองได้ในหน้าตั้งค่า หากแก้ข้อมูลพร้อมกันหลายเครื่อง แอปจะให้สำรองข้อมูลในเครื่องก่อนโหลดข้อมูลจากคลาวด์

## การแจ้งเตือนบน iPhone

Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม → เปิดแอป → ตั้งค่า → เปิดแจ้งเตือน ไม่ต้องกรอกรหัสเชื่อมต่อ เปิดแยกแต่ละเครื่อง และเปิดใหม่เมื่อเปลี่ยนบัญชี เครื่องอื่นต้องเปิดแอปเพื่อรับกำหนดเตือนล่าสุด

[ความเป็นส่วนตัว](https://padppp66.github.io/braindump/privacy.html)

## ซอร์สโค้ด

ไฟล์ที่รากคลังเป็นเว็บพร้อมใช้บน GitHub Pages (main → root) ซอร์ส React/TypeScript, ระบบแจ้งเตือน และฐานข้อมูลอยู่ใน braindump-source.zip ใช้ Node.js 22.13 ขึ้นไป: npm ci, npm test, npm run build

ตั้งค่าตาม supabase/README.md และ push-server/README.md ก่อนสร้างเว็บ ซอร์สไม่รวมกุญแจลับหรือไฟล์ .env.local
