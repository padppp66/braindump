# BrainDump — วางแผนการเรียน

[เปิดเว็บ](https://padppp66.github.io/braindump/)

เว็บภาษาไทย เพิ่มงาน จัดตาราง เตรียมสอบ และติดตามการเรียน เก็บข้อมูลในเบราว์เซอร์แต่ละเครื่อง

## การแจ้งเตือน

- ตั้งค่า → เปิดข้อความเตือนในเว็บ → เลือกเตือนก่อนกำหนดส่ง 15 นาที / 1 ชั่วโมง / 1 วัน → บันทึก
- เพิ่มกำหนดส่งลงปฏิทินมือถือได้จากตั้งค่า ไฟล์ .ics ไม่ซิงก์อัตโนมัติ ต้องตรวจเวลาเตือนในปฏิทินและแก้เองเมื่อเปลี่ยนงาน
- เชื่อมบริการ Cloudflare แล้ว เปิดจากไอคอนหน้าจอโฮม → ตั้งค่า → ใส่รหัสเชื่อมต่อ → อนุญาตและเปิดแจ้งเตือน → ทดสอบแจ้งเตือน การรับบนหน้าจอล็อกต้องอนุญาตบนเครื่องนั้น และยังต้องทดสอบบน iPhone จริง
- โค้ดระบบ Push และคู่มือติดตั้งอยู่ในโฟลเดอร์ push-server ภายใน braindump-source.zip

## ซอร์สโค้ด

ดาวน์โหลด braindump-source.zip แล้วแตกไฟล์ ใช้ Node.js 22.13 ขึ้นไป: npm ci, npm test, npm run build

ไฟล์ที่รากคลังเป็นเว็บพร้อมใช้ ส่วน React/TypeScript และระบบแจ้งเตือนที่แก้ไขได้อยู่ใน ZIP

## ใช้บน iPhone

เปิดเว็บใน Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม ข้อมูลไม่ซิงก์ข้ามเครื่อง สำรองข้อมูลก่อนล้างเบราว์เซอร์
